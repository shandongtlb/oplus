- 开放系统认证：发三次请求，抓到来自 AP、发往本机的 sequence 2 / status 0

## 两项明确问题

1. **monitor 缺 WEXT 兼容。** `iw dev wlan0 info` 正确，但 `iwconfig` 显示
   no wireless extensions，`aireplay-ng --test -a ... wlan0` 以 channel -1 退出，
   尚未发包。核对真实频道后加 `--ignore-negative-one` 可工作。
   参考实现已在 [sam 主补丁](../../sam/补丁/0001-wlan-native-monitor-injection.patch)，具体是
   `hdd_mon_wext_giwname/giwmode/siwmode/giwfreq/siwfreq/giwrange`、
   `hdd_mon_wext_handler_def`，以及 `hdd_mon_mode_ether_setup()` 中的
   `dev->wireless_handlers = &hdd_mon_wext_handler_def` 接线；还包含
   `wlan_hdd_mon_wext_set_freq()` 的并发/频道语义。当前 peach v6 尚未带上这段，
   下一轮直接按该补丁移植并验证；实际换频道仍走 nl80211，避免 RTNL 下等固件。
   oplus 也已提供 [0011 WEXT 查询桥](../补丁/qca_inject/0011-fix-wext-for-qcamonitor.patch)
   和 [0012 WEXT 补充](../补丁/qca_inject/0012-fix-wext+waittime.patch)，仅作历史参考。
2. **RX-only 阶段 qdisc 留帧并跨频道补发。** 80 MHz 下尝试一帧 Probe，驱动
   accepted 维持 1057，但 qdisc backlog=44 bytes/1 packet；不再发新包，切回
   信道 1 / 20 MHz 后 accepted/submitted/completed 都变成 1058、backlog 清空。
   宽信道期间没有提交，但旧帧随后被提交到新频道。需补充主机 qdisc 生命周期，
   不能只清内部 WMA 队列；必须区分有界队列背压与 RX-only 拒发。

另有工具环境限制：非交互 airodump 缺 UTF-8/终端时不能正常记录；设好 UTF-8、PTY
及 `SHELL=/bin/sh` 后可记录，但 SIGINT 超时仍未正常退出，需要 SIGKILL 兜底。
当前证据不足以归因于驱动。
